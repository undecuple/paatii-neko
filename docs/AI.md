# How AI was used

The port is developed by one person with AI coding agents, working in sessions the maintainer directs. The agents do
most of the hands-on work: reading the game's program and the reference material, writing and testing patches, tools
and documentation, and running the builds and test runs. The game and its files are only handled inside a sandbox,
with the game files read-only and no network access. The maintainer sets the goals and priorities, plays the builds,
reviews and signs off everything that is published, and is responsible for it. Status claims are dated and say how
they were checked; guesses are marked `ASSUMPTION:` in the code until they are confirmed in the game's program. The
PS3 emulator RPCS3 is read as a reference, never copied. Nothing the game ships (art, sound, text) is generated or
altered, and this repository contains no AI-made art. If you find a statement here that was not verified, please
open an issue.
