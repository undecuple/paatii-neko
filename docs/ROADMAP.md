# Roadmap

In order of priority. No dates: each step is done when it is checked in a run.

1. **Minigames:** the remaining minigames, one by one, with the game's original controls, each played to its score
   screen.
2. **Sound and saves:** music and effects checked by ear; a save loaded again after a restart.
3. **Speed:** the game's own 30 frames per second in every mode, measured with the hardware and build named.
4. **Windows:** a test on real Windows, then an installer that builds the port on the player's PC.
5. **Later:** a native Linux build (Vulkan), and optional display features such as an upscaler.

Any gameplay change stays optional. What a release must meet: [RELEASE-CRITERIA.md](RELEASE-CRITERIA.md).
